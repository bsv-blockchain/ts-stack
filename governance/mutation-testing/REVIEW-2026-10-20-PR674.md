## Iteration contract

1. State one invariant, the failing or unknown observation, the independent test
   oracle, exact source/runtime and a bounded execution budget. Start with the
   existing owning tests and prior failed mutation locations.
2. Add or correct the smallest owning assertion. Keep positive behavior,
   negative cases and original property histories. A focused diagnostic may
   select explicit mutation locations, but must identify itself as partial and
   cannot supply a complete target score.
3. Record elapsed setup/initial/mutation time, observed failures, assertion
   kills/timeouts/survivors, uncovered/invalid/unexecuted counts, resource faults
   and the remaining unknowns. Record process/worker limits and contention;
   unknown CPU, machine or monetary cost is not zero. A kill is evidence that a
   test detects a fault, not proof of a newly discovered product bug.
4. Inspect progress after ten minutes. If initial setup dominates or no useful
   result is available, diagnose that bottleneck instead of launching another
   broad campaign. Preserve the original job's verdict and stop/drain an
   unproductive diagnostic at the declared feedback budget. Never extend an
   original timeout, reduce 300 histories or relax a threshold to get a pass.
5. After a relevant fix passes the bounded check, run the complete affected
   target with its original selectors and global gates. Batch related changes
   before one ordinary CI push. Run the exhaustive campaign as final
   qualification, after known high-priority failures have been addressed.

Every evidence entry must distinguish tested commit and working diff, exact
input/control digests, command, Node/Stryker versions, seed/path, original limits,
terminal status, raw-report digest and actual physical drain. Preserve failed,
interrupted and cancelled samples. A later pass never rewrites their verdicts.
All original tests, 300-history properties, seed `3242026`, replay path, engine
pins, deadlines, score/status floors and canonical tuples remain governed.
