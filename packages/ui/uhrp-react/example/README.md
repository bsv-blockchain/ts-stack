## Example

This example is linked to the `uhrp-react` package in the parent directory for development purposes.

From the workspace root, run `pnpm --filter @bsv/uhrp-react build` followed by
`pnpm --filter uhrp-react-example start`. The image demonstrates UHRP resolution.
The video demonstrates direct URLs with `Source` and includes a local caption
track so it can play independently of storage-provider availability.
