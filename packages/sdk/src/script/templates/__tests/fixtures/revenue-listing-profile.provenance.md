# Frozen replacement-profile lock vectors

`revenue-listing-profile.json.gz` contains the unchanged output-zero locking
scripts from the authorized genesis and public-link activation transactions in
BRC PR295's positive wire corpus at immutable source
`1b9a75e497b5856675af1ce01fd86843c37d07f9`, plus that corpus's descriptor.
The compressed source archive has SHA256
`a8f130d7b0fd89fb301e9327ecef2eb5f39374efb6ade9d7fc0b88c11c63e2eb`.
The 5926-byte extracted fixture has SHA256
`902151000a6e191f680f8b21c400c57b717f26af7591d2c9aafecdada5002cd6`.

The fixture establishes exact portable codec interoperability with the two
literal programs and shared metadata. It neither generates transaction variants
nor establishes Bitcoin validity, a signed genesis, complete lineage, chain
currentness, private release or production wallet/miner integration. Those
require their separate complete-input and domain qualification.
